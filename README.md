### 🧑‍💻 About Me

I'm a **DevOps Engineer** focused on building reliable cloud infrastructure, automating deployments, and embedding **Shift-Left Security (DevSecOps)** into modern application delivery. 

- ☁️ **Multi-Cloud Infrastructure:** Designing resilient, cost-optimized architectures on **Azure, AWS & Google Cloud**.
- 🏗️ **Infrastructure as Code (IaC):** Provisioning modular, state-locked cloud environments using **Terraform & Ansible**.
- 📦 **Containers & Orchestration:** Containerizing and scaling microservices with **Docker, Kubernetes & Helm**.
- 🔁 **CI/CD & GitOps:** Automating zero-downtime delivery pipelines via **Jenkins, GitHub Actions, GitLab CI & ArgoCD**.
- 🔐 **DevSecOps & Security Gates:** Enforcing automated code & IaC security checks with **tfsec, TFLint, Trivy, SonarQube & Gitleaks**.
- 📊 **Observability & Scripting:** Building proactive monitoring dashboards (**Prometheus, Grafana**) and automating operations with **Linux, Bash & Python**.
- 🤝 **Collaboration:** Open to collaborating on production-grade **Cloud, DevOps, CI/CD & DevSecOps** architectures.
